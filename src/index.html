          In English
          
            
          font-kku, in short
          
            
          font-kku (폰꾸) is a browser runtime that builds a Korean Hangul font from eight drawn cells: draw ㄱ ㄴ ㅁ ㅅ ㅇ ㆍ ㅡ ㅣ by hand or ask an AI, and the runtime assembles the remaining jamo and all 11,172 modern syllables on the page.
          
          
          
          
          
            
            
              
          • Eight cells, not thousands of glyphs. Redrawing one cell changes every syllable that uses it.
            • 
              
          • An AI answer is a font. The cells fit in one chat reply, so a model that reads the usage guide returns a complete font as one HTML file.
            • 
              
          • Every jamo is a node. Initial, medial and final are separate elements: color, animate or vary them with page CSS.
            • 
              
          • Scope. Titles and short phrases, JavaScript in the browser; TTF/WOFF comes from the 40-cell sprite path.
            •
