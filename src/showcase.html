청첩장에서 게임까지

청첩장·간판·게임 화면·학습지처럼 폰꾸로 꾸민 페이지를 모았습니다. 마음에 드는 것을 그대로 가져가도 되고, 글씨를 내가 그린 8칸으로 갈아 고쳐 써도 되고, 요청 글 하나로 새 페이지를 만들어도 됩니다.

하나 그대로 쓰기 마음에 드는 사례의 HTML 한 장을 복사하거나 내려받아 글만 바꿉니다. 내 서버에 올려도 그대로 열립니다. 사례 고르기 ↓ 둘 고쳐 쓰기 폰꾸 글씨를 AI가 그린 8칸이나 내가 그린 8칸으로 갈아 끼웁니다. 등록 코드와 획 굵기 규칙, 글꼴 속성만 바뀌고, 페이지 CSS로 자모마다 준 움직임은 그대로 남습니다. 고쳐 보기 ↓ 셋 새로 만들기 만들 페이지와 글씨를 고르면 AI에게 줄 요청 글이 나옵니다. 직접 짜려면 스크립트 한 줄과 8칸에서 시작합니다. 요청 글 만들기 ↓

쓰임마다 골라 보기

초대장·간판·학습지·게임 화면·방송 자막·발표 표지처럼 쓰임이 저마다 다른 페이지입니다. 쓰임으로 골라 열어 보세요. 카드마다 그대로 가져가기(HTML 복사·내려받기), 고쳐 보기, AI에게 고쳐 달라기가 있습니다.

가져가는 HTML은 런타임 주소가 jsDelivr의 정확한 판 압축본(@tty.link/font-kku@0.1.4-rc.1/font-kku.min.js)으로 바뀌어 있어 내 서버에 올려도 그대로 열립니다. 카드에 붙은 세벌식 표는 글꼴 이름을 비워 기본 배치로 그린 글자입니다.

사례를 불러오는 중…

AI에게 고쳐 달라기는 설명서 주소와 그 사례의 주소가 든 요청 글을 복사합니다. 바꿀 것만 적어 대화창에 붙여 넣으세요. 링크를 열지 못하는 AI에게는 HTML 복사로 받은 글을 함께 붙여 넣습니다.

둘 고쳐 쓰기

글씨를 갈아 끼우면

사례 하나를 골라 폰꾸 글씨를 8칸 그림 세트로 갈아 끼워 보세요. 미리보기와 복사하는 HTML은 같은 글에서 나오고, 바뀐 줄은 따로 보입니다. 글과 색은 받은 HTML에서 그대로 고치면 됩니다.

고쳐 쓰기는 사례 HTML을 읽어 와야 해서 file:// 주소에서는 막힙니다. 저장소 뿌리에서 python3 -m http.server처럼 정적 서버로 열어 보세요.

사례를 고르면 바뀐 줄이 여기에 보입니다.
  • 글꼴이 가진 꾸밈은 글꼴과 함께 바뀝니다 — 네온의 빛, 금박의 금빛, 분필 가루가 그렇습니다. 페이지 CSS로 자모마다 준 색과 움직임(네온 간판의 받침 ㅂ 깜빡임 같은)은 그대로 남습니다.
  • 8칸 세트는 아직 글꼴 파일(TTF·WOFF)이 되지 않습니다 — 웹 페이지와 작업실 파일로 씁니다.
  • 칸을 더 다듬으려면 — 소개의 8칸 만들기에서 그리고, 글꼴 작업실의 8칸 그리기에서 이어 그립니다. 소개에서 그린 칸은 이 브라우저에 남아 위의 '내가 그린 8칸'으로 고를 수 있습니다.

    터미널 배너와 봇
    
            
    
              figlet 같은 배너 도구에는 한글 글꼴이 없습니다. 폰꾸는 같은 분해 규칙으로 한글을 두 줄 평문으로 풀어 써서 터미널 배너·빌드 로그·봇 메시지에 넣습니다.
              글자가 커지는 것이 아니라 풀어 쓰는 것이고, 슬랙·디스코드는 코드 블록으로 감싸야 줄이 맞습니다.

    슬랙 봇 (Bolt for JavaScript)
    
                
    const { App } = require("@slack/bolt");
const { renderText } = require("@tty.link/font-kku");

const app = new App({
  token: process.env.SLACK_BOT_TOKEN,
  signingSecret: process.env.SLACK_SIGNING_SECRET,
});

// /banner 배포 완료  →  한글을 두 줄로 풀어 쓴 배너
app.command("/banner", async ({ command, ack, respond }) => {
  await ack();
  const banner = renderText(command.text || "배포 완료").join("\n");
  await respond("```\n" + banner + "\n```");
});

app.start(3000);
