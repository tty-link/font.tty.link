재료와 깊이

한글을 원리대로, 여러 깊이로 그린다

배치는 그대로 두고 자모를 무엇으로 채우는지 바꾼다. 획을 CSS 상자로 긋거나(element, 기본 — 받을 파일 없음), 기기 한글 글꼴을 표준 자리에 맞추거나(device), 사람·AI가 그린 그림 세트로 그린다(svg). 세 재료는 같은 배치를 쓴다 — 세벌 고정이면 같은 도장이다(ADR-026). 그림 세트는 그린 만큼이 깊이다. 그리지 않은 자모는 짝·선 조립식·가획·천지인으로 조립하고, 그림이 맡지 않은 획(ㅋ의 더한 획, ㅏ의 점)은 그 세트의 원소 그림(@line·@dot·@ring)으로, 없으면 ㅡ·ㆍ·ㅇ 그림으로 긋는다 — 둘 다 없을 때만 CSS 상자다(ADR-024·025). 덜 그린 셈 치는 미리보기는 디자인 소스의 보이는 칸(cells)으로 한다.

--fy-face: element jamo-set="dunggeun-box" FontKku.stagePreview(set, "origin8") · authoringProgress --fy-element-width · --fy-element-cap data-fy-layout · FontKku.layoutStability(host)

조작

깊이 사다리

같은 그림 세트를 이 층까지만 그린 셈 치고 본다(FontKku.stagePreview) — 그 위의 그림은 없는 셈 친다. 렌더러 모드가 아니라 제작 안내다.

  • 확장 40 — 자음 19·모음 21을 모두 그림으로. 겹받침만 짝(ㄺ = ㄹ + ㄱ)
  • 기본 24 — 자음 14·모음 10. 쌍자음·이중모음은 짝(ㄲ = ㄱ + ㄱ, ㅘ = ㅗ + ㅏ)
  • 원형 8 — ㄱ ㄴ ㅁ ㅅ ㅇ, ㆍ ㅡ ㅣ. 가획(ㅋ = ㄱ + 획), ㅎ = ㆍ + ㅡ + ㅇ, 이체 ㄹ과 ㅂ·ㅍ은 ㅡ·ㅣ 선, 천지인(ㅏ = ㅣ + 점). 더한 획과 점도 그 세트의 그림(원소 그림 @line·@dot, 없으면 ㅡ·ㆍ)이라 CSS 상자가 남지 않는다
  • 원소 3 — @line @dot @ring만. 모든 자모를 획 하나씩
  • CSS 원소 — 그림 없이 획을 CSS 상자로

배치

세벌 고정(기본)은 타자기처럼 초성·중성·종성을 역할마다 정해진 자리와 크기로 찍는다 — 앞 다섯 글자의 초성 ㄱ, 뒤 네 글자의 ㅏ는 어느 글자에서나 같은 도장이고 받침 자리는 늘 비워 둔다. 재료를 바꿔도(그림 세트) 도장은 같다. 세벌 문맥은 글꼴을 밝힌 font="sebul"의 배치로, 모음과 받침에 따라 자리와 크기가 바뀌고 과·곽의 윗부분은 그 글꼴의 고를 재서 따른다(ADR-026, ADR-024 §2). 아래 줄은 data-fy-layout과 FontKku.layoutStability(host) — 같은 역할·자모 노드의 자리·크기·변환이 모두 같으면 stable이다.

재료

같은 배치, 다른 재료. 아래 줄은 그 바탕 요소가 쓴 그림(그림 세트) 또는 재료다. 그림 세트의 선 그림은 화면에서 원소 획과 같은 굵기로 긋고(획 굵기 칸이 둘 다 바꾼다), 붓 세트처럼 칠한 그림은 그림 그대로 늘어난다. ㄹ·ㅌ·겹받침처럼 평행 획이 촘촘한 자모는 획이 0.75–1배로 가늘어져 작은 글씨에서도 틈이 남고, ㅎ·ㅊ의 꼭지는 가로획과 떨어진다(ADR-024 §3).

제작 단계

고른 그림 세트를 원형 8 → 기본 24 → 확장 40만 그린 셈 치고 미리 본다(제작 안내 — 렌더러 모드가 아니다). 덜 그릴수록 그림이 적게 쓰이고 조립이 는다.

자모 해석

자모마다 고른 그림의 차례 — 그 자모 그림 → 짝 → 선 조립식(ㅎ = ㆍ + ㅡ + ㅇ, ㄹ·ㅂ·ㅍ = ㅡ·ㅣ) → 가획 조상 → 천지인 → 원소 그림 → 원형 그림(남은 획을 ㅡ·ㆍ·ㅇ으로) → CSS 상자. ▭는 CSS 상자, +는 획 묶음 사이다.
