재료와 깊이

한글을 원리대로, 여러 깊이로 그린다

세벌·고딕의 배치는 그대로 두고 자모를 무엇으로 채우는지 바꾼다. 기기 한글 글꼴을 표준 자리에 맞추거나(device), 획을 CSS 상자로 긋거나(element, 받을 파일 없음), 사람·AI가 그린 그림 세트로 그린다(svg). 그림 세트는 그린 만큼이 깊이다 — 그리지 않은 자모는 짝·가획·천지인·원소로 조립한다(ADR-024). 덜 그린 셈 치는 미리보기는 디자인 소스의 보이는 칸(cells)으로 한다(ADR-025).

조작

깊이 사다리

그림 세트에서 어느 층까지 그림을 쓸지 고정한다. 그 위의 그림은 없는 셈 친다.

  • 확장 40 — 자음 19·모음 21을 모두 그림으로. 겹받침만 짝(ㄺ = ㄹ + ㄱ)
  • 기본 24 — 자음 14·모음 10. 쌍자음·이중모음은 짝(ㄲ = ㄱ + ㄱ, ㅘ = ㅗ + ㅏ)
  • 원형 8 — ㄱ ㄴ ㅁ ㅅ ㅇ, ㆍ ㅡ ㅣ. 가획(ㅋ = ㄱ + 획), ㅎ = ㆍ + ㅡ + ㅇ, 이체 ㄹ과 ㅂ·ㅍ은 ㅡ·ㅣ 선, 천지인(ㅏ = ㅣ + 점)
  • 원소 3 — @line @dot @ring만. 모든 자모를 획 하나씩
  • CSS 원소 — 그림 없이 획을 CSS 상자로

배치

세벌 고정(기본)은 타자기처럼 초성·중성·종성을 역할마다 정해진 자리와 크기로 찍는다 — 위 줄의 초성 ㄱ, 아래 줄의 ㅏ는 어느 글자에서나 같은 도장이고 받침 자리는 늘 비워 둔다. 세벌 문맥은 글꼴을 밝힌 sebul의 지금 배치로, 모음과 받침에 따라 자리와 크기가 바뀐다(ADR-026).

재료

같은 배치, 다른 재료. 아래 줄은 그 바탕 요소가 쓴 그림(그림 세트) 또는 재료다.

제작 단계

고른 그림 세트를 원형 8 → 기본 24 → 확장 40만 그린 셈 치고 미리 본다(제작 안내 — 렌더러 모드가 아니다). 덜 그릴수록 그림이 적게 쓰이고 조립이 는다.

자모 해석

자모마다 고른 그림의 차례 — 그 자모 그림 → 짝 → 선 조립식(ㅎ = ㆍ + ㅡ + ㅇ, ㄹ·ㅂ·ㅍ = ㅡ·ㅣ) → 가획 조상 → 천지인 → 원소 그림 → 원형 그림(남은 획을 ㅡ·ㆍ·ㅇ으로) → CSS 상자. ▭는 CSS 상자, +는 획 묶음 사이다.
