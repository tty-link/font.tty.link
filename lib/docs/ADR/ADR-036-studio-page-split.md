# ADR-036: 작업실 페이지 나누기 — 디자인 · 고치기 · 자소판 · 검수

## Status
Accepted (2026-10-17) — 사용자가 2026-10-17에 결정했고 같은 날 구현해 master에 로컬 병합했다. 결정 문서는 2026-10-31 문서 정비(PLAN-DOCS-001)에서
PLAN·MEMORY·작업실 문서에 흩어져 있던 기록을 모아 썼다. [ADR-009](ADR-009-font-editor-v2.md) §1의 "하나의 정적 스튜디오 페이지"를 대신한다.

## Date
2026-10-17

## Context
- 사용자 지적(2026-10-16): "지금 작업실이 너무 여러 기능이 한 페이지에 있어서 복잡한 것 같은데, 각각 페이지 나누는게 좋지 않을까?",
  "직접 마우스로 끌어서 크기나 위치 등 바꾸는 기능이 완전하지 않은 것 같아", "'의' 같은 글자에서 ㅇ 조작도 안되고".
- 한 페이지에 다섯 갈래 일(디자인·CSS 고치기·자소판·검사·검수)이 쌓여 미리보기의 위끝이 첫 화면 밖(1,168px)으로 밀렸다
  ([작업실 직접 조작·화면 구성 검토](../NOTES/studio-direct-manipulation-review-2026-10-16.md)).
- [ADR-009](ADR-009-font-editor-v2.md) §1은 CSS 편집과 재료 편집을 하나의 정적 페이지로 통합하기로 했다. 그 뒤 디자인 도구(ADR-025)·
  자소판·검수(ADR-031)가 더해지며 한 화면이 감당하지 못하게 되었다.
- 고른 안: 페이지 나누기(사용자). 고르지 않은 안: 한 페이지 안 단계 탭(추천안이었음), 지금 구조 정리.

## Decision
1. **작업실은 네 페이지다.** 디자인(`?page=design`, 맨 주소) · 고치기(`?page=edit`) · 자소판(`?page=sheet`) · 검수(`?page=review`).
   페이지 사이는 초안·프로젝트로 넘긴다.
2. **새 기능은 맞는 페이지에 둔다.** 한 페이지에 기능을 다시 쌓지 않는다. 직접 조작(끌기·손잡이·키)은 고치기 페이지의 기준이다.
3. **받아들인 비용(결정 때):** 되돌리기 기록이 페이지마다 끊길 수 있는 것, 사이트의 삽입(mount)이 페이지를 골라야 하는 것.
4. **구현 방식:** 페이지는 주소가 다른 화면이지만 **한 문서**다. 칸마다 보일 페이지를 밝히고 CSS가 나머지를 감춘다. 페이지 고리는 문서를 다시
   싣지 않고 `?page=`만 바꾼다(`history.pushState`). 그래서 고친 것·되돌리기 기록·mount 연결이 이어지고, 3의 첫째 비용은 실제로 생기지 않았다.
   따로 된 HTML 문서로 나누면 그림 세트 등록·프로젝트 조각이 페이지마다 끊긴다(모듈이 서로의 상태에 기댄다).
5. **자동화 계약:** `FontStudio.page()`·`FontStudio.setPage(name)`, 훅 `FontStudio.on("page", fn)`. 페이지 이름은 `design`·`edit`·`sheet`·`review`다
   (`studio/font-studio-api.js`의 `PAGES`).

## Alternatives Considered
### 한 페이지 단계 탭
- 설명: 같은 페이지에서 단계 탭으로 칸을 바꾼다(검토 때의 추천안).
- 장점: 주소·삽입이 하나다.
- 단점: 기능이 다시 한 화면에 쌓이기 쉽다. 사용자가 고르지 않았다.

### 지금 구조 정리
- 설명: 칸 배치·접기만 다듬는다.
- 단점: 미리보기를 첫 화면으로 되돌리지 못한다.

### 페이지마다 따로 된 HTML 문서
- 단점: 그림 세트 등록·디자인·프로젝트 상태가 페이지마다 끊긴다. 한 문서 안 페이지(4)로 대신했다.

## Consequences
### Positive
- 미리보기가 각 페이지의 첫 화면에 들어온다. 페이지마다 한 갈래 일만 보인다.
- 감춰진 페이지의 모듈은 쉬고(2026-10-18 PLAN-STUDIO-002 S1 모듈 수명), 무거운 모듈은 늦게 싣는다.

### Negative
- 사이트·개발·검수 사이트가 작업실을 삽입할 때 페이지를 골라야 한다(mount 옵션).
- 새 탭으로 연 주소는 새 작업실이다(초안이 있으면 초안 막대로 잇는다).

### Risks
- 기능이 맞는 페이지를 찾지 못하면 다시 한 페이지에 쌓인다 — 새 기능을 더할 때 페이지를 먼저 정한다.
