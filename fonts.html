글꼴과 테마

폰꾸는 글자 모양을 여섯 축으로 나눠 고릅니다. 뼈대가 되는 글꼴 위에 꾸밈을 칠하고, 씨앗으로 변주하고, 움직임과 상호작용을 얹고, 바탕을 고릅니다. 축마다 고른 것은 서로 섞이므로, 꾸밈 하나를 어느 글꼴에나 걸 수 있습니다.

    테마는 축을 고른 조합에 붙인 이름입니다 — 고장 난 네온 = 세벌 + 네온 + 깜빡임 + 어두운 바탕

    테마 고르기 직접 조합하기 글꼴 견본 폰꾸로 만드는 글꼴
    하나 테마 — 이름 붙은 조합

    마음에 드는 테마를 고르세요

    카드마다 어떤 축을 골랐는지 적혀 있습니다. 코드 복사는 그대로 여는 HTML 한 장이고, 조합기에서 열기로 축 하나만 바꿔 나만의 조합을 만듭니다.

    둘 조합기 — 축마다 하나씩

    직접 섞어 보세요

    여섯 축을 하나씩 고르면 견본과 코드가 함께 바뀝니다. 테마에서 출발해도 되고, 조합 뽑기로 무작위 조합을 받아도 됩니다. 고른 조합은 주소에 담겨 링크 복사로 나눕니다.

    HTML 한 장
    셋 글꼴 — 첫째 축, 뼈대

    글꼴 견본과 시험대

    글꼴은 자모를 어디에 어떤 크기로 놓는지(짜임)와 무엇으로 긋는지(획)입니다. 문장·크기·바탕을 바꿔 비교하고, 글꼴마다 꾸미기로 색·외곽선·그림자·변주를 얹은 나만의 꾸밈 글꼴 CSS를 만듭니다.

    씨앗

    폰꾸로 만드는 글꼴

    폰꾸는 글꼴을 쓰는 도구이면서 만드는 도구입니다. 글꼴 파일은 글자 그림을 담지만 폰꾸는 글자를 그리는 규칙을 담습니다. 그래서 있는 글꼴 위에 꾸밈을 얹고, 주사위를 섞고, 자모 40칸만 그려 한글 11,172자를 만듭니다.

    나만의 글꼴

    꾸미기

    글꼴 하나를 바탕으로 초성·중성·받침 색, 외곽선, 그림자, 변주, 움직임을 바꿔 나만의 꾸밈 글꼴 CSS 한 파일로 가져갑니다.

    꾸미기 문서
    글꼴 뽑기

    글꼴 뽑기 뽑기 ·

    뽑기 씨앗 하나로 기반 글꼴·색·외곽선·그림자·변주·움직임을 무작위로 고릅니다. 같은 뽑기 씨앗은 언제나 같은 글꼴이라 링크로 나눌 수 있습니다.

    하하하하 하하하하

    씨앗 변주

    정해진 모양 대신 그릴 때마다 자모 표정이 달라집니다. 같은 글자를 반복해도 똑같지 않고, 씨앗을 고정하면 언제나 같은 모양으로 돌아옵니다.

    씨앗 문서
    내 손글씨

    자소판 그리기

    자음 19·모음 21, 40칸만 그리면 한글 11,172자가 됩니다. 작업실 재료 탭에서 펜으로 그리거나 손글씨 그림을 불러옵니다.

    자소판 그리기
    SVG 자모

    SVG로 자모 그리기 · AI에게 맡기기

    자모를 SVG로 직접 그려 새 그림 자소 글꼴을 만듭니다. 설명서 링크를 주면 AI 에이전트가 붓글씨·크레용·도트 자모를 그려 줍니다.

    SVG 문서
    글꼴 파일

    글꼴 파일로 내보내기

    그림 자소 글꼴을 보통 글꼴 파일(TTF)로 받아 문서 편집기·디자인 도구·앱에서 씁니다. 11,172자를 브라우저에서 몇 초 만에 만듭니다.
