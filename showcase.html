알림과 로그를 크게

HTML이 아닌 곳에서는 한글을 2줄 평문으로 풀어 강조합니다. 슬랙·디스코드는 코드 블록으로 감싸야 줄이 맞습니다.

#배포-알림 · 슬랙 미리보기

            

            

              

                
슬랙 봇 (Bolt for JavaScript)

                
const { App } = require("@slack/bolt");
const { renderText } = require("font-kku");

const app = new App({
  token: process.env.SLACK_BOT_TOKEN,
  signingSecret: process.env.SLACK_SIGNING_SECRET,
});

// /big 배포 완료  →  한글을 2줄로 크게
app.command("/big", async ({ command, ack, respond }) => {
  await ack();
  const big = renderText(command.text || "배포 완료").join("\n");
  await respond("```\n" + big + "\n```");
});

app.start(3000);
